View course online at: [https://computation-structures.github.io/course](https://computation-structures.github.io/course)

You can view this course material using just your computer, i.e., no
internet access required after the initial setup.

* clone this repository onto your local computer.  Also install <a href="https://www.python.org/downloads/">python3</a> on your computer.

* change to directory where you cloned the repo.

* execute `python3 -m http.server` to start a local HTTP server listening on port 8000.

* browse to <a href="http://localhost:8000/">http://localhost:8000/</a> to see the
top-level webpage for the course.


Grading Configuration Header
====

Every graded part of this material is possible to download student work for offline storage or grading. You can download and upload preexisting or saved student work in the grading configuration header. Please note that inspecting the grading configuration or uploading work that does not belong to a student circumvents the purpose of assessment, which is to identify gaps in student understanding.

If you are working with an instructor on this material, the instructor may have software that will allow them to supervise student work in real-time or provide guidance while you complete the assignments. If you have an instructor webhook and key, you can enter them into the grading configuration header to enable this supervision mode.
